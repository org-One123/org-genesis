# Guía de Aprendizaje - Sprint 1

## 🎯 Objetivo General
Establecer el marco de trabajo colaborativo, configurar la estructura base del repositorio Git con plantillas institucionales de desarrollo y plasmar la planeación inicial del proyecto.

---

## 📚 Módulos y Temáticas del Sprint

1. **Gestión de Versiones y Git Flow**
   - Configuración de reglas de colaboración y revisores automáticos (`CODEOWNERS`).
   - Gestión de Pull Requests e Issues.

2. **Metodología Ágil y Scrum**
   - Redacción de Historias de Usuario bajo estándares Gherkin (Dado que / Cuando / Entonces).
   - Establecimiento del *Definition of Done* (DoD) del equipo.

3. **Arquitectura del Proyecto**
   - Organización de directorios en `src/` para mantener limpio el entorno de desarrollo. 

---

## 📦 Entregables del Sprint
* Repositorio Git estructurado con la carpeta `.github` y sus plantillas funcionales.
* Documentación técnica completa en `/docs`.
* Esqueleto inicial de la aplicación configurado dentro de la carpeta `/src`.
