# Rúbrica de Evaluación - Sprint 1

| Criterio de Evaluación | Excelente (100%) | Aceptable (70%) | Insuficiente (0-50%) |
| :--- | :--- | :--- | :--- |
| **Estructura del Repositorio** | La carpeta `.github`, `docs` y `src` están correctamente ubicadas y pobladas con sus archivos requeridos. | Faltan detalles menores o algún archivo secundario dentro de la estructura. | No se utilizó la estructura de carpetas solicitada para el proyecto. |
| **Historias de Usuario** | HUs estructuradas formalmente, asociadas a criterios de aceptación claros e independientes. | HUs redactadas pero carecen de criterios de aceptación detallados. | Las historias de usuario no siguen el formato estándar o están incompletas. |
| **Configuración de Colaboración** | Archivos `CODEOWNERS` y `PULL_REQUEST_TEMPLATE.md` configurados y vinculados correctamente. | Archivos presentes pero con sintaxis errónea en las asignaciones de usuario. | Ausencia de configuración para revisión de código o colaboradores. |
| **Definition of Done (DoD)** | DoD definido con criterios medibles de calidad, pruebas, Git y documentación. | DoD muy básico o con vacíos técnicos importantes. | No se definió el archivo DoD. |
